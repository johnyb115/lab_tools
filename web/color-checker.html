WCAG Contrast ratios

Ratio of each color pair against the chosen background. AA requires ≥ 4.5:1 for normal text, ≥ 3:1 for large text / UI. AAA requires ≥ 7:1 / ≥ 4.5:1.

Pair distinguishability

Minimum contrast between any two palette colors — important for distinguishing data series in a chart. Pairs with ratio < 3:1 may be confused.
