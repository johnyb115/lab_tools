🌀 EIS Plotter

Upload one or more electrochemical impedance spectroscopy exports and get a Nyquist plot and a Bode plot (|Z| and phase vs. frequency), overlaid across every loaded run. Everything runs locally in your browser.

Data

Supported formats: CSV, semicolon-CSV, TSV, whitespace-delimited ASCII (.txt/.asc) and Excel (.xlsx/.xls). The first row of each file is treated as column headers. You can drop multiple files at once to overlay several runs.
📄 Click or drop CSV / ASCII / XLSX files

Export

Exports frequency, Z′, Z″, |Z| and phase for every mapped file, long-form with a file column. To save a chart image, use the camera icon in its own toolbar.
