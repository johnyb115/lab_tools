📈 Universal Data Plotter

Upload one or more CSV, whitespace-delimited ASCII, or XLSX files, choose an X column and any number of Y columns per file, and combine them into a single chart. Colors, axis labels, log scales and trace style are all adjustable — the plot updates live as you change any control.

Data

Supported formats: CSV (comma or semicolon), TSV, whitespace-delimited ASCII (.txt/.asc) and Excel (.xlsx/.xls). The first row of each file is treated as column headers. You can drop multiple files at once.
📄 Click or drop CSV / ASCII / XLSX files

Chart options

The plot updates automatically whenever you check/uncheck a series or change an option — there's no separate "apply" step. To save a PNG, use the camera icon in the plot's own toolbar (top-right of the chart).
