## Direction contract

THESIS: Every tool is a die on one reticle, drawn with a picture of its own output, so a group member finds and recognises the right tool at a glance. Refuses the dark-SaaS card grid with emoji tiles.
OWN-WORLD: Quartz ground / chrome-black shell, 1px scribe lanes, square corners, oxide-chart category inks (one colour = one category), yellow-room amber only on pressable things, Geist + Geist Mono, die codes and coordinates in mono.
STORY: The visitor sees what each tool produces, picks it by picture, code or file format (search, `/`), and lands on a tool page whose header, panel markers and accents carry that category's colour.

Below it the reticle: category key column (solid oxide square + letter) and die grid; each die = code, coordinate, output drawing on a category tint, name, verb-first summary, formats.
